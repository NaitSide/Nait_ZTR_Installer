# Локальные пакеты

Установщик сначала использует совместимые локальные DEB-пакеты и проверяет SHA-256.
При отсутствии подходящего пакета используется существующий онлайн-путь установки.
Несовпадение контрольной суммы останавливает установку, а не вызывает загрузку замены.

Compose: `docker-compose-v2_2.40.3+ds1-0ubuntu1~24.04.1_amd64.deb`,
14 788 638 байт. Целевая система: Ubuntu 24.04 amd64 с Docker из пакета `docker.io`.
Зависимость: `libc6 >= 2.34`, штатно присутствует в Ubuntu 24.04.

Источник: официальный архив Ubuntu,
https://archive.ubuntu.com/ubuntu/pool/universe/d/docker-compose-v2/docker-compose-v2_2.40.3+ds1-0ubuntu1~24.04.1_amd64.deb

SHA-256 проверен по метаданным APT Ubuntu и записан в `SHA256SUMS`.
Для Docker CE выбирается `docker-compose-plugin`: пакет Ubuntu автоматически к нему
не подмешивается. Пока совместимого локального CE-пакета нет, используется APT
из уже настроенного репозитория Docker. Работающий Compose не переустанавливается.

Это локальный комплект основных пакетов, а не полностью автономная установка
на любую чистую машину: Docker Engine, базовый образ `ubuntu:24.04` и зависимости
сборки ZTNCUI могут требовать доступа к репозиториям. Они в этот комплект не входят.
